# 词汇映射

SillyTavern 的文本净化与局部 AI 改写扩展。用规则直接替换或删除不想保留的词句；需要时只让 AI 改写被规则命中的句子。附带规则预设、范围保护、净化前文透视、深度净化、更新检查与匿名反馈。

文档分工：本文件面向使用者；代码结构见 [ARCHITECTURE.md](ARCHITECTURE.md)；版本差异见 [CHANGELOG.md](CHANGELOG.md)。

---

## 安装

1. 把整个扩展目录放进 `SillyTavern/data/<用户>/extensions/`，目录名可任意（插件按实际加载路径解析自身位置）。
2. 刷新酒馆页面，在「扩展」面板启用「词汇映射」。
3. 顶栏工具栏出现「词汇映射」按钮，点击打开工作台。

**不能只拷 `index.js` 与 `style.css`。** `index.js` 直接按相对路径 `import` `src/` 下的模块，缺 `src/` 插件不会启动（控制台报模块加载失败，不是语法错误）。

### 样式构建（仅改样式的人需要）

`style.css` 是产物：由 `build-css.mjs` 把 `styles/` 下 30 个分文件按 `styles/ORDER.json` 的顺序拼接压缩而来，同时产出 `style.css.map`。发布包里它已经是构建好的，直接安装即可。

改了 `styles/` 或 `src/` 之后：

```bash
node build-css.mjs     # 合并压缩 + token 级等价校验 + 生成 sourcemap
node build-check.mjs   # 构建闸门，十三条机械校验（与上一步相互独立，必须单独跑）
```

两步都通过才算改完，随后刷新酒馆页面——ESM 与 CSS 都走浏览器缓存。

## 快速开始

1. 打开工作台，新建或导入一套规则预设。
2. 在「净化」页启用需要的规则合集；普通规则直接替换或删除命中内容。
3. 需要 AI 时到「AI」页开启「启用改写」，配置接口与模型，并把对应规则的处理方式设为「AI 改写」。
4. 需要自动调用就同时开启「自动触发 AI 改写」；只想手动触发时关掉它，普通规则不受影响。
5. 想确认改了什么，点消息旁的「净化前文透视」看 Diff、追踪命中规则或撤回净化。
6. 要让旧聊天或世界书按新规则重跑，用「深度净化」。

## 界面

工作台是覆盖层，含五个页面。宽屏导航在左侧竖栏，窄屏在底部。

| 页面 | 负责 |
| --- | --- |
| 首页 | 规则总览与切换、规则条目编辑、批量编辑、状态统计、搜索（实时 + 历史） |
| AI | AI 改写双开关、接口与模型、生成参数、全局提示词、改写诊断、通信记录 |
| 净化 | 标签作用范围、应用标签列表与分组、深度净化入口 |
| 工具 | 预设绑定解析与绑定记录、版本与更新、附加功能（AI 改写快捷键、净化结果楼层数、数据库联动、简繁转换） |
| 反馈 | 运行日志、AI 上下文、深度清理诊断、提交反馈 |

顶栏左侧是当前页标题与说明，右侧依次为导览、主题切换、关闭。宽屏时左侧导航纵贯整列，顶部为插件标识。600px 以下搜索、编辑分组、编辑规则、子规则四个弹窗改为整屏，并适配刘海安全区。手机端首页每个规则分组用 1px 描边和 14px 圆角包成独立卡片，分组边界更清楚。

**主题**五档，点顶栏主题图标展开下拉后选择，结果持久化：跟随酒馆 / 素白 / 暖米 / 墨夜 / 柔灰。素白为灰白画布 + 白色分区；暖米参考浅色编辑器的米白画布，用米色底 + 深灰字；墨夜为原来的深蓝夜间；柔灰为 Nord 系中性冷灰底 + 低亮度冷灰字。后两者都按护眼原则避开纯白纯黑与高饱和色：暖米取 Solarized 系赤陶强调色，柔灰取 Nord 系柔绿强调色，不走蓝系。跟随酒馆时强调色与正文色取自酒馆主题。插件内的下拉选项在各主题下都使用自身配色，不受酒馆 `select option` 覆盖。

输入框、文本域、下拉框统一是**微灰填充、无边框**：不输入时不给描边，靠一层比卡片略深的填充表示「这里可以输入」；获得焦点时才出现一圈内描边，且不占位、不引起布局抖动。

## 规则净化

三种匹配模式：**普通文本**、**简易通配**、**正则表达式**。

- 规则按集合分组，可单独启停、排序、搜索、批量管理。首页规则卡的标记与规则正文使用和编辑弹窗相同的 13px 字号：标记加粗，正文常规。
- 首页卡片左侧铅笔直接进编辑，右侧「⋯」菜单为 **上移 / 下移 / 复制 / 移动 / 删除**；复制生成「原名 副本」并追加到末尾。
- 搜索是**边打字边搜**（220ms 去抖）：框内左侧常驻放大镜，输入后右侧出现清空按钮；下方保留最近 10 条关键词，可复用、单条删除或全部清空。历史存在浏览器本地。
- 编辑规则弹窗顶部可按 **全部 / AI 改写 / 程序改写** 筛选子规则，只影响显示，不改动保存顺序。
- 一条规则可配置多个替换候选，每次命中独立随机选择；不填替换内容则删除命中文本。
- 简易通配用 `*` 匹配一小段内容，`{A,B,C}` 表示多个候选写法。
- 正则支持捕获组替换（`$1`、`$2`）与内联高亮；语法错误翻译成中文说明（如「字符组没有闭合，请检查 [ 与 ] 是否成对」）。
- 启用简繁兼容后，普通文本与简易通配按词典扩展常见简繁变体，正则里的中文字面字符也参与匹配。

处理顺序固定：**先 AI 局部改写，再程序规则净化。**

## 预设与绑定

一套预设 = 一组规则 + 一套 AI 配置。预设可导入、导出、复制、转移，可设为全局默认；AI 接口预设（Base URL / Key / 模型 / 采样参数）独立管理。

「工具 → 预设绑定解析」有三层绑定，命中顺序 **当前角色 → 对话补全预设 → 全局预设**：

| 绑定 | 作用 |
| --- | --- |
| 全局预设 | 未命中角色或补全绑定时的默认值 |
| 当前角色 | 角色卡命中时使用 |
| 对话补全预设 | 按当前使用的补全预设命中 |

右上角「显示绑定记录」列出历史角色绑定与补全预设绑定；指向已删除预设的条目标为失效，可就地清理。

## 范围保护

两种全局标签模式，二选一：

- **保护特定标签**：跳过列表内标签包裹的内容，只处理标签之外。
- **净化特定标签**：只处理列表内标签包裹的内容。

「应用标签列表」标题行右侧是两个独立按钮：「新建标签」「新建分组」（新建分组先要求填名字）。每个分组名右侧为 **滑动开关 + 编辑按钮 + 下拉菜单**：开关控制整组生效，编辑按钮就地改名，菜单提供上移、下移、删除。默认分组不可删除，首尾分组自动禁用无效方向。标签操作收在卡片「⋯」菜单里，菜单在分组框之外展开，下方空间不足时向上弹出。

此外可以跳过用户消息，并在深度净化时保护用户人设（Persona 描述）。

## 净化前文透视

消息旁入口查看当前 Swipe 分支的处理记录，按「原文 → AI 改写（如有）→ 程序规则净化」组织：AI 阶段比较原文与 AI 结果，程序阶段比较执行前后文本；没有 AI 阶段时直接比较原文与程序结果。可看片段或全文、追踪命中规则、随时撤回。

撤回规则：

- 撤回**不要求**当前正文与记录完全一致。
- 记录里仍在原位、未被手动改动的片段还原成原文。
- 手动改过的片段保持原样；因手动编辑而定位不到的替换直接跳过。
- 正文与记录不一致时，界面提示这次撤回会保留你的改动。

识别到的完整 `<UpdateVariable>` 块不进入正文差异展示。对比文本只保留设置的历史条数范围内（默认 3，可设 1–20）；旧记录退出保留范围后不再提供完整阶段对比，但撤回保护与「切回 Swipe 不重复净化」仍然有效。

## AI 改写

只处理被「AI 改写」规则命中的句子，不是整篇润色。

**前置条件**：酒馆助手（JS-Slash-Runner）可用，且在「AI」页配置了 Base URL / API Key / 模型。插件使用自己配置的接口，不改用 SillyTavern 当前主模型。

**两个开关**：「启用改写」是总开关，「自动触发 AI 改写」只控制普通聊天中的自动调用（默认开启）。关闭总开关后「自动触发」置灰；同时所有「AI 改写」类型规则被过滤，只跑程序规则，流式临时替换一并失效——自动与手动入口都生效。「AI」页连接说明下方也会直接提示这件事，点旁边的 i 图标可查看完整执行顺序。

**范围**：默认在被指定的 XML 正文范围内找命中内容，留空则按整条助手消息处理。按完整句子提取，识别中英文句末标点、引号、括号等边界。完整 `<UpdateVariable>` 块从 AI 目标与上下文中排除，但不改变程序规则的作用范围。

**重新改写**：当前分支仍有原文记录时以该原文为来源，否则用当前正文；符合当前追加格式的尾部内容会保留。正文已改动、无法精确对应时，不做模糊定位，也不覆盖整条旧快照。

**排错顺序**：总开关 → 接口与模型 → 规则是否命中 → XML 标签是否闭合 →（自动调用时）自动触发是否开启。「AI」页提供改写诊断与通信记录（最近 10 次实际调用）。

> 改写会把命中范围内的正文与上下文发送到你自己配置的接口，请自行确认该服务的隐私政策。

## 深度净化

处理**已经存在**的内容，不是接下来新生成的消息。

**范围只有两项**：当前角色卡绑定的世界书、当前角色卡的聊天记录。被 `/hide` 宏隐藏的楼层同样参与，并在复核界面标注「已隐藏」。角色卡正文、Persona 描述、其他角色、其他世界书、其他聊天、Shujuku 数据都不进入。

**规则预设**：开始前可在运行设置里选一个已保存的规则集，本次运行按该预设执行，结束后全局当前预设不变。

**两种模式**：只跑程序规则，或「程序 + AI」。默认先预览、按条编辑建议结果，再决定是否应用；也可选择直接应用跳过复核。

打开或切换聊天不会自动重新净化历史记录。文本比较在后台任务执行，切换复核条目或应用前会等当前比较完成——后台比较不等于零开销。

## 反馈与更新

「反馈」是第 5 个导航页，页内四个标签：运行日志、AI 上下文、深度清理诊断、提交反馈。工具页继续负责版本信息与更新检查，有可用更新时可直接更新并刷新。

运行日志按发生时间正序记录最近 100 条事件，时间固定用北京时间，阶段名与原因、模式、来源都翻成中文；未进入改写流程的空转事件（酒馆试运行、后台生成、没有进行中的生成）会按 30 秒间隔合并成一行，只保留时间区间与条数。

每个日期分隔行后面标出当天的事件条数。日志标题行右侧两个动作：**日期正序 / 日期倒序**（切换后记在本地，下次打开还是这个顺序）、**清空日志**（二次确认后同时清掉内存与本地存储）。已移除「复制日志 / 导出日志」按钮；提交反馈时仍可通过表单勾选附带插件日志。

反馈支持提交 Bug 与功能建议，可附加运行环境、插件日志、深度清理诊断，也可主动选择图片、PDF、文本或 JSON 附件（最多 5 个，每个不超过 10 MiB）。发送前先展示实际准备提交的 JSON 与文件清单，确认后才上传。

简繁词典装在工具页：状态条显示「未安装 / 下载失败 / 安装成功」，失败时给出原因并提供「重新下载」。

## 兼容与提示

- 适配常规聊天、Swipe、消息编辑、流式与非流式生成。
- 处理 TauriTavern、柏宝箱、LoreFrame、MVU 等扩展场景；这些扩展自身更新后，兼容行为可能随之变化。
- Shujuku 是可选兼容项，不是必需依赖；AI 改写需要酒馆助手提供生成能力。
- 数据库自动净化会在每次行更新前核对所属聊天、消息、隔离空间与目标单元格；切换聊天或目标失效后停止旧任务的后续提交。已发出的单次写入由数据库插件负责，不可撤销。
- 同时启用多个会修改同一段正文的方案时，尽量避免重复处理同一内容。

## 数据与安全

- 深度净化在扫描与复核阶段不改写资源，正式修改发生在确认应用之后；直接应用会跳过复核。
- 设置主键固定为 `ultimate_purifier_ai_rewrite`（改显示名不影响数据），迁移逻辑只处理旧命名空间 `..._modified` 与更早的 legacy 键。
- 匿名反馈里的诊断与文件只在你主动勾选或选择后附加；提交前请确认不含敏感内容。
- 正则与简易通配不要写出能匹配空字符串的规则。
- 不希望被处理的内容，优先用范围标签、跳过用户消息或人设保护明确排除。
